# ChinaCare Navigator

Static landing page prototype and planning package for a multilingual international patient navigation service in China.

## What this includes

- Landing page: `index.html`, `styles.css`, `script.js`
- Hero image asset: `assets/hero-concierge.png`
- GitHub Pages workflow: `.github/workflows/pages.yml`
- Planning documents:
  - `docs/business-plan.md`
  - `docs/financial-model.md`
  - `docs/operations-sop.md`
  - `docs/pitch-outline.md`

## Local preview

Open `index.html` directly in a browser.

## GitHub Pages

This repository includes a GitHub Actions workflow that publishes the site root to GitHub Pages when changes are pushed to `main`.

## Compliance note

This prototype describes patient navigation, translation, appointment coordination, and administrative support. It does not present the platform as a medical provider and does not offer diagnosis, prescription, treatment advice, or outcome guarantees.
