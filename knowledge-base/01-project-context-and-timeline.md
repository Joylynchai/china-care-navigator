# 01. 项目背景与阶段记录

## 项目一句话

ChinaCare Navigator 是一个面向海外人士来中国就医、体检和专科问诊的多语言导医与医疗服务协调平台。

平台的核心定位不是医疗机构，也不提供诊断、处方或治疗建议，而是提供：

- 病历整理与翻译
- 体检/专科访问路径设计
- 医院和医生预约协调
- 多语言导医与陪同
- 支付、发票、保险理赔材料协助
- 海外客户和中国医疗机构之间的操作层连接

## 已完成的重要讨论

1. 验证项目方向是否成立  
   结论：成立，但应从“非医疗服务协调”切入，避免直接承诺医疗结果。

2. 市场冷启动选择  
   初步判断俄罗斯/俄语市场、英语高收入人群、中东高净值客户、韩国短途体检客户都具备测试价值。

3. 官网示意图与落地页  
   已完成静态官网、多个市场落地页、合作伙伴页、隐私政策和条款页。

4. GitHub Pages 部署  
   已部署到 `gh-pages` 分支，并确认线上可访问。

5. 商业计划书、财务模型、运营 SOP、竞品报告  
   已形成正式 Markdown 文档，并进一步生成 HTML 报告页。

6. BP PPTX  
   已生成可下载的 10 页商业计划摘要 PPTX。

7. AI 与运营讨论  
   结论：AI 是效率工具，不是客户付费的全部理由。客户真正付费的是确定性、审核、医疗场景理解、医院协同和责任边界。

8. 跨境支付讨论  
   结论：平台服务费和医院医疗费必须分离。平台收自己的服务费，医疗费用尽量由客户直接支付给医院。

## 当前阶段判断

项目已经从“想法”推进到了“可对外展示的概念验证资产”阶段。下一阶段的核心不是继续扩写材料，而是用现有官网和报告去验证：

- 是否有真实海外客户愿意付费
- 哪些市场获客成本最低
- 哪些医院/体检机构愿意合作
- 哪些服务包毛利最高且交付最稳定
