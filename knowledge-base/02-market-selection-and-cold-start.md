# 02. 市场选择与冷启动判断

## 市场选择原则

首批市场不能只看人口规模，而要看四个变量：

1. 来华便利度  
   包括距离、航班、签证便利、免签政策、是否已有来华旅游流量。

2. 支付能力  
   是否能为体检、专科问诊、翻译、导医和保险资料服务付费。

3. 医疗需求差异  
   是否存在本国等待时间长、费用高、服务体验差或跨境就医习惯。

4. 获客可达性  
   是否能通过社群、旅行社、企业、保险经纪、医疗中介、内容营销触达。

## 首批候选市场

### 俄罗斯/俄语市场

优势：

- 地理距离近，跨境医疗和旅游具备历史基础。
- 对中国医疗资源有一定认知。
- 俄语服务供给相对稀缺，平台可通过语言和信任建立差异化。
- 可从专科问诊、康复、体检、二诊切入。

风险：

- 支付、制裁和跨境金融路径需要单独设计。
- 客户信任建立周期可能较长。
- 需要俄语医疗翻译和本地渠道。

适合产品：

- Specialist Visit Setup
- Medical File Pack
- Full Visit Companion

### 欧美英语市场

优势：

- 支付能力高。
- 对私立医疗、体检、第二意见、专科预约有明确消费习惯。
- 适合通过英文官网、SEO、LinkedIn、外籍社区和企业福利渠道触达。

风险：

- 对医疗质量、隐私、责任边界、保险认可要求更高。
- 获客成本可能较高。
- 对平台可信度要求极高。

适合产品：

- Executive Checkup Starter
- Insurance Documentation Pack
- Second Opinion Coordination

### 中东/GCC 市场

优势：

- 高净值医疗旅游客户多。
- 对陪同、翻译、VIP 服务接受度较高。
- 高客单价可以覆盖重运营成本。

风险：

- 对接待规格、隐私、宗教/饮食/家庭陪同需求要求高。
- 需要阿语能力和高端医院资源。
- 初期没有强背书时获客难度较高。

适合产品：

- VIP Companion
- Executive Checkup
- Specialist Referral Coordination

### 韩国市场

提出韩国纳入首批市场的理由包括：

- 韩国距离中国近，短途出行成本低。
- 中国对部分入境游客开放免签或便利化政策，韩国游客来华旅游有增长基础。
- 韩国半导体、科技、商务人群有较高消费能力。
- 可把体检作为短途旅行附加服务。

验证后的判断：

韩国可以作为首批市场中的“小规模测试市场”，但不宜一开始押注为主市场。

原因：

- 韩国本国医疗体系成熟，体检和医美服务都很强。
- 韩国人来中国做常规体检的刚需不如俄罗斯、中东或部分英语外籍人士明显。
- 更适合测试“来华商务/旅游顺便体检”的轻产品，而不是重医疗转诊。

适合产品：

- Korean Visitor Checkup
- 1-day/2-day Checkup Add-on
- 企业员工短途体检服务

## 冷启动优先级建议

第一优先级：

- 俄语专科/二诊客户
- 英语高收入体检客户

第二优先级：

- 韩国短途体检客户
- 中东高端陪同客户

第三优先级：

- 泛全球医疗旅游平台式扩张

## 冷启动验证指标

每个市场至少验证：

- 100-200 个有效询盘
- 20-40 个付费客户
- 5-10 个真实到院案例
- 2-3 个稳定供给合作方
- 真实毛利率是否达到预期
