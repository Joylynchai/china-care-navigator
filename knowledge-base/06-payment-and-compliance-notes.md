# 06. 跨境支付与合规边界

## 支付设计总原则

平台只收自己的服务费，医疗费用尽量由客户直接支付给医院。

这样可以降低：

- 第三方支付牌照风险
- 代收代付风险
- 外汇结算风险
- 大额退款和拒付风险
- 医疗纠纷时的平台责任
- 税务收入确认混乱

## 款项分离

| 款项类型 | 建议收款方 | 平台角色 |
| --- | --- | --- |
| 文件整理费 | 平台 | 直接收取服务费 |
| 翻译费 | 平台 | 直接收取服务费 |
| 预约协调费 | 平台 | 直接收取服务费 |
| 导医陪同费 | 平台 | 直接收取服务费 |
| 医院体检费 | 医院 | 平台提供支付指引 |
| 医疗治疗费 | 医院 | 平台不代收 |
| 住院押金 | 医院 | 客户直接支付 |
| 保险材料服务费 | 平台 | 直接收取服务费 |

## 海外客户可用支付方式

平台服务费可支持：

- Visa / Mastercard / Amex
- UnionPay International
- PayPal
- Apple Pay / Google Pay
- 国际银行转账
- 企业客户发票付款

到中国后的医疗费用可支持：

- 医院 POS 刷卡
- 支付宝绑定国际银行卡
- 微信支付绑定国际银行卡
- 银联卡
- 现金
- 医院指定银行转账

## 可参考的政策和公开信息

中国政府 2024 年发布优化支付服务的政策，要求改善老年人、外籍来华人员等群体支付便利性，推动移动支付、银行卡、现金等并行。

## 平台不应做的事

1. 不承诺替客户保管大额医疗资金。  
2. 不把医院医疗费作为平台收入。  
3. 不模糊服务费和医院费用。  
4. 不承诺保险一定报销。  
5. 不替医院出具医疗发票。  
6. 不在没有合规安排时做类似资金托管或 escrow 的服务。  

## 推荐支付流程

1. 客户支付 case review fee。  
2. 平台完成初步资料审核。  
3. 客户支付文件包/预约/导医服务费。  
4. 平台提供医院费用预估和支付说明。  
5. 客户直接向医院支付医疗费用。  
6. 服务结束后，平台协助整理医院发票、报告和保险材料。  

## 合同表达建议

合同中应明确：

- 平台不是医疗机构。
- 平台服务费不包含医院费用。
- 医院费用由客户与医院直接结算。
- 平台不保证诊断、治疗结果或保险报销结果。
- 翻译和摘要仅用于沟通便利，医学判断以医院医生为准。
