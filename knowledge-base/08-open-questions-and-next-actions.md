# 08. 未验证问题与下一步行动

## 当前最重要的未验证问题

### 1. 客户是否愿意在出行前付费

需要验证：

- 是否愿意为 Medical File Pack 支付 USD 199-399
- 是否愿意为 Specialist Visit Setup 支付 USD 399-799
- 是否愿意为 Full Visit Companion 支付 USD 1,500+

### 2. 哪个市场最容易冷启动

需要用真实投放或渠道测试比较：

- 俄语客户
- 英语高收入体检客户
- 韩国短途体检客户
- 中东高端客户

### 3. 医院是否愿意配合

需要验证：

- 是否接受海外客户预约
- 是否支持英文/外语报告
- 是否支持国际银行卡/支付宝/微信/现金
- 是否能开具保险理赔所需材料
- 是否愿意给平台固定对接人

### 4. 人工审核成本是否可控

需要记录：

- 每个文件包平均处理时长
- AI 初稿错误率
- L2 审核耗时
- 客服沟通次数
- 到院当天异常率

### 5. 跨境支付链路是否顺畅

需要验证：

- 海外客户付款成功率
- 拒付率
- 退款处理时长
- 医院直接收款成功率
- 不同国家客户偏好的支付方式

## 下一阶段 30 天行动

1. 选 2 个市场做付费测试  
   建议：英语体检客户 + 韩国短途体检客户，或英语体检客户 + 俄语专科客户。

2. 签 3-5 个供给方  
   包括体检中心、国际部医院、专科门诊、医学翻译、导医人员。

3. 建立服务报价单  
   固定 Medical File Pack、Checkup Starter、Specialist Visit、Companion 四类产品。

4. 建立客户 intake 表单  
   记录客户国家、语言、需求、时间、预算、已有资料、保险情况。

5. 建立真实 case log  
   每个案例记录询盘来源、转化、收入、成本、处理时间、异常和复盘。

## 下一阶段 90 天目标

- 100-200 个有效询盘
- 20-40 个付费客户
- 5-10 个真实到院案例
- 5-8 个可靠供给方
- 完成至少 2 个语言市场的真实转化比较
- 验证服务包毛利率和运营瓶颈

## 当前建议

不要急着做复杂 App。先用官网、表单、人工服务、AI 后台辅助和标准化 SOP 跑出 20-40 个真实订单。真实订单数据比继续扩展功能更重要。
