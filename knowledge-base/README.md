# ChinaCare Navigator 过程资料库

本文件夹用于沉淀项目从想法验证到官网上线过程中的关键讨论、判断和操作记录。它和 `docs/` 的区别是：

- `docs/`：偏正式交付物，例如商业计划书、财务模型、运营 SOP、竞品调研报告。
- `knowledge-base/`：偏过程资料库，记录为什么这样做、哪些假设需要验证、后续如何继续推进。

## 文件索引

1. `01-project-context-and-timeline.md`  
   项目目标、阶段进展、已经完成的资产与部署情况。

2. `02-market-selection-and-cold-start.md`  
   首批市场选择逻辑，包括俄罗斯、欧美、中东、韩国等市场的适配度。

3. `03-competitor-and-positioning-notes.md`  
   竞品格局、差异化定位，以及平台不应直接做医疗服务方的原因。

4. `04-business-model-pricing-and-economics.md`  
   收费方式、产品包、收入结构、毛利逻辑和市场想象空间。

5. `05-ai-and-operations-design.md`  
   AI 在导医平台中的作用、人机协同边界、人工审核要求和重运营程度。

6. `06-payment-and-compliance-notes.md`  
   海外客户跨境支付方案、医疗费与服务费分离、合规边界。

7. `07-website-deployment-log.md`  
   官网、报告中心、PPTX 下载、GitHub Pages 部署记录。

8. `08-open-questions-and-next-actions.md`  
   当前未验证假设、下一阶段优先事项和建议执行动作。
