# 医院 BD 清单 v0.1

## 1. 目标

第一阶段不追求医院数量，优先拿 5-8 家真实可履约机构，覆盖体检、专科门诊、国际部、影像、康复和乐城路径。

## 2. 优先城市

| 城市 | 角色 | 首批资源方向 |
| --- | --- | --- |
| 上海 | 国际化和高端体检 | 私立国际医院、公立国际部、高端体检中心 |
| 北京 | 三甲专科和二诊 | 公立三甲国际部、肿瘤/心血管/骨科资源 |
| 广州/深圳 | 商务客和电子产业链 | 体检、眼科、牙科、国际门诊 |
| 青岛/大连 | 韩国实验线 | 韩语导医友好机构、体检、康复 |
| 海南乐城 | 特许药械和康养 | 乐城机构、健康管理、康复、特许药械咨询 |

## 3. 医院合作必问问题

| 模块 | 问题 |
| --- | --- |
| 外籍接诊 | 是否接收外国护照？是否需要提前备案？ |
| 语言 | 是否有英文/韩文/俄文报告？是否允许第三方翻译陪诊？ |
| 预约 | 体检、普通门诊、专家门诊分别需要提前多久？ |
| 付款 | 是否支持 Visa、Mastercard、境外汇款、现金、支付宝/微信？ |
| 发票 | 是否可开 fapiao、英文费用明细、诊断说明？ |
| 病历 | 是否提供英文摘要、DICOM、检查原始数据？ |
| 保险 | 是否支持国际保险直付或理赔材料协助？ |
| 价格 | 是否有外籍患者价格表和体检套餐表？ |
| 投诉 | 国际患者纠纷和退款如何处理？ |
| 合同 | 能否签运营服务、翻译服务、国际患者协调服务协议？ |

## 4. 合作模式

推荐：

- 平台向患者收取服务费；
- 医疗费由患者直接支付给医院；
- 医院端可采购翻译、客服、国际患者运营外包或系统服务；
- 明确平台不参与诊疗、不承诺疗效、不收医生个人返佣。

避免：

- 医疗费比例抽佣；
- 医生返点；
- 暗示优先专家号；
- 用治疗结果做营销；
- 医院未授权即使用医院名称做广告。

- 合同框架。
