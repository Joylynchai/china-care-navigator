# 运营 SOP v0.1

## 1. 服务边界

平台可以做：

- 客户需求收集；
- 病历整理和翻译；
- 医院/科室路径协调；
- 预约支持；
- 陪诊口译；
- 报告、发票、DICOM、保险材料整理；
- 复诊提醒。

平台不能做：

- 诊断；
- 处方；
- 治疗方案；
- 医院疗效排名；
- 治愈率承诺；
- 保险报销承诺；
- 未批准疗法推广。

## 2. 客户流程

1. 客户提交咨询表；
2. L1 case manager 做可接单判断；
3. 客户签署隐私授权、医疗免责声明、服务协议；
4. 客户支付基础咨询费或 Medical File Pack；
5. 上传病历、影像、用药、过敏史、既往治疗资料；
6. AI 做 OCR、摘要、时间线和缺失资料初筛；
7. L2 医学翻译/审核人员复核；
8. 输出医院 intake pack 和报价；
9. 客户确认服务包并付款；
10. 平台协调医院预约；
11. 陪诊译员执行到院任务；
12. 交付报告翻译、文件包和复诊提醒。

## 3. 人员分层

| 层级 | 角色 | 责任 |
| --- | --- | --- |
| L1 | Case manager | 客户沟通、报价、预约、流程跟进 |
| L2 | 医学翻译/护士审核 | 翻译审核、病历结构化、资料完整性 |
| L3 | 合作医生/医院端医生 | 复杂病例医学意见、二诊、接诊判断 |

## 4. 病历审核清单

- 患者姓名、性别、年龄、护照信息是否一致；
- 诊断名称是否来自原始资料；
- 日期线是否完整；
- 用药名称、剂量、频率是否正确；
- 过敏史是否标注；
- 手术史是否标注；
- 影像结论是否完整；
- 病理和基因检测是否缺失；
- 是否存在 AI 自行解释诊疗结论；
- 是否需要客户补充 DICOM、出院小结、病理玻片或费用明细。

## 5. 高风险病例规则

以下病例必须转 L3 或拒接：

- 肿瘤治疗路径；
- 罕见病；
- 神经系统疑难病；
- 重症/ICU；
- 未成年人重大疾病；
- 代孕、非法辅助生殖、未备案干细胞、未经批准基因治疗；
- 客户要求平台承诺疗效或报销。

## 6. 陪诊任务规则

- 出发前确认医院、科室、预约时间、证件、付款方式；
- 陪诊员只做翻译和流程协助，不解释医疗结论；
- 医生诊疗意见应由医院正式报告、病历或医生书面/口头意见形成记录；
- 超时服务按小时或半天计费；
- 每次到院后填写陪诊记录。

## 7. 售后和纠纷

- 医疗结果争议转医院处理；
- 翻译错误由平台复核并更正；
- 保险拒赔不得承诺由平台负责；
- 所有退款依据服务协议和已完成服务节点判断；
- 复杂投诉 24 小时内由负责人介入。
