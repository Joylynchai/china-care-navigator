# ChinaCare Navigator 商业计划 v0.1

## 1. 项目定位

ChinaCare Navigator 是面向国际患者的多语言来华导医与就医协调平台，提供病历整理、医学翻译、医院预约、陪诊口译、体检协调、保险文件包和复诊跟进。

平台不提供诊断、处方、治疗方案或疗效承诺。所有医疗服务由中国持牌医疗机构提供。

## 2. 核心客户

首批市场分为四条线：

| 市场线 | 人群 | 切入服务 |
| --- | --- | --- |
| 主攻线 | 俄罗斯、蒙古、中亚 | 专科预约、二诊文件、俄语陪诊、康复/中医 |
| 高客单线 | 英国、加拿大、澳新、海外华人 | 高端体检、影像检查、英文报告、保险文件 |
| 扩展线 | 海湾国家 | VIP 体检、阿语协调、家庭陪同、乐城路径 |
| 实验线 | 韩国游客、在华韩国人、半导体商务客 | 韩语导医、短程体检、上海/青岛商务体检 |

## 4. 竞争策略

现有竞品包括 SinoHealth、MediLink China、Orient Health China、乐城官方服务平台、Bookimed、Vaidam 等。差异化策略：

- 先做俄语、英语、阿语、韩语四个明确市场，而不是泛全球；
- 把病历整理、医院 intake pack、保险文件包做成标准产品；
- 用 AI 降低后台处理成本，但用人工审核保证交付质量；
- 合规表达克制，不发布疗效承诺、医院排名或治疗保证；
- 从 C 端服务切入，逐步扩展到企业健康管理、医院国际患者运营外包、保险/TPA 对接。

## 6. 关键风险

- 医疗广告和诊疗边界风险；
- 海外客户信任不足；
- 医院合作不稳定；
- 获客成本高；
- 陪诊和翻译质量不可控；
- 保险报销预期管理失败；
- 复杂病例纠纷。
