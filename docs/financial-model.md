# ChinaCare Navigator 财务模型 v1.0

更新日期：2026-06-04

## 1. 模型口径

本模型仅测算平台服务收入，不把医院医疗费计入平台收入。医院体检、检查、药品、住院、治疗、手术等费用原则上由客户直接支付给医疗机构。

核心财务逻辑：

> 平台不是靠医疗费抽佣赚钱，而是靠导医、翻译、文件、预约、陪诊、企业健康管理和医院运营外包赚钱。

## 6. 月度盈亏平衡

汇率粗略按 USD 1 = RMB 7.2。

### 6.1 轻量测试

固定成本：RMB 80,000/月  
平均服务收入：USD 800 = RMB 5,760  
直接毛利率：55%  
获客成本率：20%  
贡献毛利率：35%

盈亏平衡订单：

RMB 80,000 / (RMB 5,760 * 35%) = 约 40 单/月

### 6.2 正式测试

## 9. 关键财务风险

1. 广告获客质量低，咨询量高但付费低；
2. 免费咨询太多，占用 case manager；
3. 复杂病例反复沟通但不付费；
4. 陪诊定价过低；
5. 医院预约反复变更导致服务成本上升；
6. 客户把平台当医生使用；
7. 保险拒赔导致投诉；
8. 医疗纠纷拖累运营。

## 10. 控制策略

- 每个病例先收 Basic Consultation 或 Medical File Pack；
- 陪诊按半天/全天/超时收费；
- 复杂病例先收费整理资料，再进入医院协调；
- 明确医院费与平台费分离；
- 建立拒接清单；
- B2B 和转介绍优先，降低获客成本；
- 用 AI 工作台减少重复劳动；
- 所有医疗判断转医院或医生。
